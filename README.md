# ExViewer iOS

使用自己的 E-Hentai / ExHentai 账号的原生 iOS / iPadOS 客户端。界面采用 SwiftUI，图片由 ImageIO 解码，最低支持 iOS 17。

## App 设计准则

[App 通用设计准则](docs/app-design-guidelines.md)包含外观与交互、代码设计和本项目的验收示例。

源码当前版本为 **1.1.0（Build 168）**。下方链接指向可下载的公开安装包。

- [Build 168 安装包与校验文件](https://github.com/xueyj96/EXViewer-iOS/releases/tag/v1.1.0-build168)

公开 IPA 不包含个人签名或设备描述文件，需要使用安装者自己的 Apple 账号签名后安装。也可以直接用 Xcode 从源码构建。已下载的 IPA 可用同一 Release 的 `SHA256SUMS` 核对。

## 功能与入口

| 入口 | 当前行为 |
| --- | --- |
| 发现 | 最新／热门／历史／搜索四个分栏；关键词、标签和高级筛选；边缘跟手循环切换，最新与热门支持下拉刷新 |
| 组合搜索 | 标题与多标签组合，包含／任一／排除、作者、上传者、画廊分类、最低评分、页数和 torrent 限制；分类支持全选与反选 |
| 记录与常用 | 通过搜索框右侧历史入口查看，按账号最多保存 100 条；搜索记录和常用组合点按直接搜索，常用组合长按编辑并支持调整顺序 |
| 标签 | 大小写与名称片段查找、本地中文词库和站点候选；一次选择多个标签，逐条修改匹配方式；高级筛选内通过“添加／常用”切换，常用标签不重复加入，候选与已选标签支持长按管理 |
| 详情标签 | 点按连续多选，顶栏显示选择数量；“新建搜索”直接使用所选标签显示结果，“加入搜索”保留已有条件并打开编辑；返回保留来源详情、标签选择和原列表位置；支持加入常用、屏蔽及解除屏蔽 |
| 阅读 | 连续／单页、四个阅读方向、按方向点击翻页、跟手拖动、缩放、进度跳转；单页相邻翻页会保留当前画面，目标图片首帧就绪后切页 |
| 沉浸阅读 | 图片按整个屏幕居中；中央单击显示或隐藏控件，空闲后自动隐藏，操作重置计时；详情从右上入口打开，左右边缘内滑返回；多帧动图按一页播放 |
| 资料库 | 稍后再读／站点收藏／阅读历史／离线下载；四个页面共享两行顶栏，阅读历史和离线下载使用同样尺寸的封面卡片 |
| 站点收藏 | 按设置中的默认分组直接加入，原生分组可在“我的 → 收藏设置”改名；调整分组与取消使用同一个完整管理页；先显示本地状态，修改立即反馈、后台同步；收藏列表支持多选移动、移除及退出多选 |
| 本机内容 | 稍后再读、阅读进度与封面恢复；阅读历史支持最近阅读、最早阅读、标题排序，稍后再读与下载另有独立排序选择 |
| 下载与缓存 | 详情页“本地下载”优先复制看图缓存，缺图才下载；离线副本独立保存，清理浏览缓存会保留；下载列表支持状态筛选和批量移除本机副本 |
| BT 种子 | 详情页“本地下载 → BT 种子”查看种子名称、大小、做种与下载人数，导出公开种子文件或复制／分享磁链，交给已有 BT 下载器 |
| 我的 | EH／EX 切换、官方网页登录、会话管理、额度与权益、常用／屏蔽标签、存储管理和收藏同步状态 |

在线画廊搜索按站点实际返回顺序展示，并自动接续分页。最低评分等条件是筛选，不会把已加载的一小部分作品伪装成全站评分、页数或标题排序。旧组合和搜索记录中的已退休排序字段可兼容读取，其余条件保持可用。

详情中的作者标签与其他标签一样，点按只选择，不直接修改当前搜索。“新建搜索”直接执行，“加入搜索”打开已有条件编辑；取消编辑保留原结果和标签选择。新搜索使用独立结果与详情路径，返回先回上一轮搜索，没有上一轮时回来源详情。合并会去除重复标签，保留原关键词、评分、分类和其他限制，原来已排除的标签仍保持排除，请求和条件错误使用短 Toast 提示；明确保存才会更新常用组合。搜索框保持单行，回车结束输入，载入或粘贴的换行转为空格。

筛选页作者输入和文本中的作者条件使用同一套搜索处理。

收藏状态按账号、EH／EX 和作品分别保存在本机，打开详情与阅读时先显示已有记录。添加、取消或移动分组会先保存最新选择、立即更新界面，再由后台逐项提交并读取结果；关闭收藏面板或继续阅读不会中断同步。连续修改以最新选择为准，较早的查询结果不会覆盖新操作。收藏列表和详情本身返回的状态也会用于更新缓存，部分列表中没出现某部作品不代表已取消收藏。

同一会话内的收藏表单可复用 10 分钟；过期时保留已有内容，后台更新不会抹掉正在编辑的分组；站点原有备注保持不变。没有持续轮询：返回前台或再次访问作品时才按需更新。状态确认后不显示额外提示；尚未完成的操作显示“待同步／同步中／结果待确认／同步失败／需要登录”。提交结果不明时只查询结果，不自动重复提交；明确未发送的网络失败可继续同步。“我的 → 收藏同步”可查看未完成项。

默认收藏分组按账号与站点保存。原生分组固定为 10 个，设置页改名会保留其他站点设置，提交后重新读取确认；正常刷新、同名重试与保存使用同一个缓存接纳流程。缓存以分组编号区分归属，旧查询不会覆盖刚确认的新名称；旧记录存在同名分组且无法区分时，只保留已收藏状态，不猜测归属。

状态缓存跨重启保存，缓存最多 5,000 条、文件最多 2 MB，清理的只是旧状态记录，不会删除站点收藏。凭证、画廊令牌和站点表单字段不写入该缓存。重启后首次编辑仍需读取表单，未完成项会在重新打开相应作品后继续处理。

登录错误根据站点响应内容识别。评论、作品标题、上传者、标签、图片文件名、收藏备注和分组中出现 `sadpanda`／`sad panda` 或登录提示文字，不再直接判定整页需要登录；真实登录提示、HTTP 拒绝、Cloudflare 验证与额度错误仍按对应原因显示。

发现／搜索结果页与资料库的两行顶部控件均保留完整圆角外框，并使用随系统浅深色变化的半透明纯色底；外框不占用额外布局高度。详情选择标签时复用现有导航栏，保留底部导航。

双栏封面按自然比例展示；极长条封面最高为列宽的两倍，超宽封面最低为列宽的一半，使用裁切预览。排布使用相同的预览尺寸估算高度；已有作品不会因封面晚到而换列。阅读器继续显示完整原图。

图片预载会随阅读位置向前补齐，翻到已完成或仍在下载的图片时复用原有结果。单张图片在现有两次请求预算内仍连接失败，只记录该页失败，保留其他健康传输；连续 3 个不同页面失败且期间没有成功加载时，才暂停整队。成功加载会清除失败累计；登录验证、额度不足和 HTTP 429 仍立即暂停。失败页不会因补齐窗口而自动反复重试，进入该页或手动重试仍遵守原有规则。图片与站点页面的并发选项均会保存并传入阅读器；预载数量表示前方目标范围，不保证该范围已全部下载完成。

看图和本地保存使用同一条普通图片链路。下载时先复用本账号的有效看图缓存，复制到独立的离线目录；没有缓存才解析并下载当前画质图片，不调用 GP 归档购买、原图付费下载或额度重置入口。重开 App 后仍可按解析出的相同图片地址复用磁盘缓存；页面与图片地址的快捷对应只在内存保留，最多 1,024 条。额度为零时可继续复制已有缓存，缺图则暂停，不自动重置额度。手动保存不受浏览缓存容量及单文件上限的自动清理规则限制。

“我的 → 阅读与存储”可开关后台下载，默认开启。关闭后仅在前台传输，离开 App 时保留队列和进度；回前台继续。开启后使用系统允许的后台执行时间，同一队列可接续下载下一部画廊，并累计报告进度；系统持续任务被停止（包括系统进度界面的取消）后，不会在同一前台立即重新申请。再次进入 App 或明确继续任务才恢复；用户在 App 手动暂停的任务保持暂停。重开 App 会将退出前的下载中任务恢复到等待队列；系统是否继续授予后台时间由 iOS 决定，不保证强制关闭后继续传输。

BT 只负责列出和导出种子，不在 App 内运行下载引擎，也不把导出种子标记成画廊下载完成。导出的种子保留原始 info 字典并核对信息哈希，外层仅保留公开的画廊 tracker；不附带登录 Cookie、个性化 tracker 参数或网页凭证。实际下载由用户已有的 BT 下载器执行，是否可完成取决于种子和做种情况。请求格式核对自 [EhPanda 的种子接口定义](https://github.com/EhPanda-Team/EhPanda/blob/main/EhPanda/App/Tools/Defaults.swift#L86) 和 [EHTracker 公开 tracker 说明](https://ehwiki.org/wiki/EHTracker/Making_a_New_Torrent)。

一张动图是一页。缓存和离线下载保留整个文件；画廊图片之外没有接入额外视频站点。账号权限、内容可见性、看图额度和归档费用由站点决定。赞助入口对应官方页面，付款由本人完成，App 不自动付款或重置额度。

## 从源码运行

1. 在 Xcode 打开 `ExViewer.xcodeproj`，选择 `ExViewer` scheme。
2. 在 Signing & Capabilities 选择自己的 Personal Team，再选择目标 iPhone 或模拟器。
3. 运行，按设备的实际提示完成开发者设置；在“我的”中进入官方网页，由本人登录和处理站点验证。

模拟器与手机会话分别保存。Simulator 构建需保留正常签名，避免 Keychain 应用身份缺失；不要对模拟器传入 `CODE_SIGNING_ALLOWED=NO`。

也可使用项目脚本：

```bash
bash scripts/install-phone.sh '<设备>' '<自己的 Team ID>'
bash scripts/verify-core.sh
bash scripts/verify-simulator.sh '<模拟器 UUID>' -only-testing:ExViewerTests/SearchRequestContractTests
```

个人签名的有效期取决于自己的描述文件。构建、安装和读取设备版本是不同步骤；不能仅凭构建成功认定已经装到手机。

## 依赖与说明

- [SwiftSoup 2.14.3](https://github.com/scinfu/SwiftSoup/releases/tag/2.14.3)：MIT，版本固定。
- 标签翻译的来源及许可保留在 `App/Resources/TagTranslation-ATTRIBUTION.json` 与 `TagTranslation-LICENSE.md`。
- [搜索规则](https://ehwiki.org/wiki/Gallery_Searching)、[元数据 API](https://ehwiki.org/wiki/API)、[额度说明](https://ehwiki.org/wiki/My_Home)、[赞助权益](https://ehwiki.org/wiki/Donation)。

界面使用 iOS 系统颜色和半透明纯色控件；图标采用独立的抽象熊猫与书本图形，满版方形资源由 iOS 处理桌面圆角。

顶栏与底栏共用单行尺寸：布局行高 44 pt、可视控件高 34 pt，栏内和外框留白使用 4 pt；标题两侧操作使用固定 34 pt 方形可视面和图标，发现／资料库的文字分栏继续按等分轨道布局。收藏管理直接在一页选择分组并保存，取消收藏只需一次短确认，不再提供备注输入。

封面可见请求与预载使用不同优先级，并保留专用封面传输容量，避免离线下载占满队列。滚动时预载可见范围前后的封面；后台更新启动快照时先尝试准备前 12 项封面，未能在预算内完成则保留旧快照，不保证任意网络条件下所有封面立即可见。
