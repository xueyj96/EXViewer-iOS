# ExHViewer 尺寸收敛实施方案

范围来自用户在 Civit Viewer 会话 01a16ca3-6777-75a0-bd9e-83cbc3367d4d 的明确要求：三类全部推进；例外追溯设计初心后取舍；不确定项先设计、独立高级审核、实施并回归。仅 ExHViewer 本地工程，不安装、不发布。保留当前未提交功能、缓存语义、固定字号及刚修好的导航。

## 第一批：同职责合并

- 共享 `FormValueMenuRow`：左侧标签只读正文色，只有右侧值/箭头可点。用于收藏管理、默认收藏分组、搜索站点和最低评分。App自有菜单内部统一AppMenu；删除搜索原生 Picker 的0.82缩放补偿。菜单项和持久状态仍归各业务model。
- 共享紧凑/常规行布局：紧凑36/footnote，常规44/subheadline；公共水平内距8。搜索子行与值行复用紧凑角色；“我的”首页保持44与12内距。不是用一个多参数组件兼容所有页面。
- 卡片表面共用 `formRowSurface`。搜索filterGroup与添加标签tagSection共用外分组容器；标题属于各页面，不塞进通用表面。账号首页分隔线从12内距+20图标槽+8间隔推导；去掉同用途10间隔和独立0.06描边。
- 移除 `GalleryRows` 的旧list分支、默认list参数和 `GalleryRow`。生产三个调用均明确grid；先查测试/预览再删。共享 `LibraryGalleryCard` 保持132高，不替换双列网格。

## 不确定项的具体设计

### 标签：按可见缝与触摸区域同时设计

保留26最小可见高、最小宽44，背景之前补足44宽，避免短标签的透明扩宽造成视觉缝不一。目标在可见面上下各增加2，单行目标至少30，长文本换行时也始终增加4，而不是只用minHeight32。TagWrapLayout行间目标不重叠，rowSpacing0；相邻行包络的可见净距为2+2=4，与横向4一致；同一行长短标签混排按顶部对齐，短项下方净距可大于4，保证最小净距4，不承诺每个短项到下一行都精确4。为保留紧凑流式排布，不把同行所有短标签强行拉高，也不引入瀑布标签布局。组框到目标上下padding2、左右4，叠加外溢后可见边距都是4。组名采用同规格。

取舍：单行触摸高32降为30，仍高于Apple当前28最小值，但低于常规44，需按密集标签角色验证；不使用负行距让命中区重叠，也不把face增高来进一步撑大标签。审核若认为30不合适，则保留32并明确接受6纵缝，不能静默破坏4pt目标。

### 字体和菜单

普通名称和主动作优先一行截断；保留阅读页码的单独缩放，因页码是完整定位信息且范围可很长。保留主底栏的0.65与标题0.8作为窄屏兜底，常规large下验证不触发。去掉搜索Picker整控件scale0.82，改共享Menu值标签（紧凑footnote），不修改菜单选项功能。默认收藏与管理菜单采用同一紧凑字号。

### 底部占位

Root以safeAreaInset预留主底栏47，WebKit已有显式避让47。实测发现FloatingFeedLayout按GeometryReader固定frame后，滚动viewport仍延伸到底栏；因此在共同容器边界采用avoidingPinnedBottomBar，主页面扣除47，localPageChrome上下文不扣。四类调用不嵌套；不能再在子列表重复扣除。普通详情现有22+64、资料库30缺少当前依据。先测滚到底最后一项与主底栏的关系，普通ScrollView只保留12内容尾间距，由页级滚动容器唯一负责；删除GalleryRows自身12尾padding，发现/收藏滚动容器在footer之后加12，稍后再读/下载的本地滚动容器统一12，历史也由自己的滚动内容末尾加12。阅读内详情同样12，靠容器安全区。若实测仍被挡，修容器占位而不是逐页加常量。禁止用“按钮能点击”代替几何不遮挡检查。

### 页面形式和状态

主导航中的下载方式由sheet改为当前NavigationStack的全页，移除内部NavigationStack/localPageChrome/medium detent；BT子页共用主底栏，系统导出仍sheet。阅读内详情原本是独立sheet内的本地NavigationStack，此入口继续在该本地栈内push下载方式/BT，保留阅读上下文且不出现主底栏，不宣称它也是主导航全屏页面。检查保存/重试后只返回当前详情，不跳过入口。

用户刚认可的无作品、mini加载、登录/请求异常布局保持。页级、inline、媒体等待分别有任务语义；现有GalleryFeedStatus/ContinuationFooter已收拢，暂不为追求少类型再合成通用状态机。把角色尺寸写进规范，避免局部复制。
