# Build 178 交互设计与验收

适用于发现、搜索、站点收藏和阅读。本页补充 [App 设计准则](app-design-guidelines.md) 和 [页面与顶底栏状态图](chrome-state-map.md)。现有尺寸、颜色和组件规格继续以 [控件与尺寸](ui-dimensions.md) 为准。

## 搜索

| 用户操作 | 页面行为 |
| --- | --- |
| 编辑关键词或高级筛选 | 清空图标只清空关键词。筛选草稿和已经展示的搜索结果各自保留，提交时才应用整套条件。 |
| 展开标签筛选、画廊分类或匹配选项 | 分组标题表明层级。分组收起时依然保留已编辑条件，确认时才提示无效条件。 |
| 从详情发起标签搜索 | 搜索结果拥有独立返回路径。回退时恢复上一份搜索或者来源详情，保留原来的标签选择和浏览位置。 |
| 进入曾执行的搜索或滚到页尾 | 可以先显示同次请求的已验证结果和续页游标。页尾预取按滚动位置触发。异常提示用短 Toast，尝试继续或重试保留明确的按钮。 |

## 站点收藏

- 站点、分组、筛选和滚动位置属于当前收藏浏览会话。切换分栏后返回时，先恢复对应位置。EH 与 EX 的浏览状态各自保留。
- 从站点返回写入结果前，界面区分当前显示、用户提交的选择和已经确认的站点状态。取消或移动收藏后，列表按已确认的结果更新，未受影响的作品保持现有列位和浏览位置。
- 收藏操作使用既有管理入口和批量操作栏。账号或站点发生变化时，过期请求不能写回当前会话。

## 阅读

- 阅读历史保存最近的有效页码。继续阅读时，当前页缓存命中就先显示该页。缺少图片时，加载状态显示在目标页，重试按钮出现在该页或连续阅读的分页边界。
- 当前页优先。相邻页已发出的请求可以在手势交接时复用，图片准备与返回、翻页和缩放保持独立。
- 从阅读返回详情或来源列表时，保留来源路径、页码和浏览位置。顶底栏按现有转场规范呈现。

## 验收入口

| 路径 | 观察点 |
| --- | --- |
| 搜索结果 → 编辑条件 → 清空关键词 → 返回 | 关键词清空范围正确。取消后，前一结果、条件和位置仍可恢复。 |
| 详情选标签 → 搜索 → 返回 | 回到对应详情或前一搜索，选择状态和滚动位置与来源相符。 |
| 收藏分组 → 滚动 → 切其他分栏 → 返回 | 恢复同站点分组和位置。取消收藏后，剩余卡片保持稳定。 |
| 历史续读 → 翻页 → 退出 → 再打开 | 回到最新已确认页。缓存仍在时优先显示该页，续页错误在对应位置可重试。 |

性能阈值、调度规则和真机计时口径见 [搜索与阅读加载设计](search-reader-performance.md)，模块依赖见 [工程架构](architecture.md)。
