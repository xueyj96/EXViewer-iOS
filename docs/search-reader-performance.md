# 搜索与阅读加载设计

## 真机样本与优化目标

| Build 177 样本 | 观测 |
| --- | --- |
| 历史续读第 5 页 | 本地文件命中到解码完成 4.4 ms，期间没有此页的图片页请求。样本起点为缓存命中，终点为解码完成。 |
| 未缓存阅读页 | 图片页解析成功 49 次，中位数 2.83 s，最长 6.33 s。图片传输成功 78 次，中位数 0.58 s。另有 44 次图片页解析取消，现有日志没有记录具体取消原因。 |
| ExHentai 搜索 `neutral` | 账号有 6 条屏蔽规则，冷暖各一轮。首条可展示项分别耗时 1.70 s 与 15 ms，首张封面解码分别耗时 2.58 s 与 17 ms。发起续页到首条新结果分别耗时 2.32 s 与 2.49 s。冷暖各加载 50 条原始结果，顺序一致。 |

续读目标是尽早显示历史页。首次读到未缓存页时，优先确保当前页和紧邻页能复用已有工作。搜索目标是降低真机滚动接近页尾时的停顿。Build 177 的 [搜索探针](../App/SearchDeviceProbe.swift) 直接调用分页模型，结果统计的终点为可展示项，手指滚动和画面呈现需另测。

## 搜索快照、续页与显式刷新

- 普通搜索入口使用 `GalleryPager.RootLoad.openSearch`，可以复用 30 秒内的完整首屏快照。快照按账号与完整首屏请求 URL 定位，命中时恢复同一份站点顺序和游标。已载入的搜索路线仍可保存自己的滚动位置。
- 快照接纳要求首批结果的标签完整，最低评分使用现有的严格校验。界面继续用当前的屏蔽条件过滤列表。同站点、同账号、同请求是复用前提，重复作品与不合法游标由快照仓库校验。
- 显式刷新使用 `GalleryPager.RootLoad.refresh`。开启新的结果加载时，过期或缺失的快照会触发站点请求。快照命中可以跳过本次首屏请求。显式刷新随时可以请求站点。前一搜索路线被取消时，分页结果需通过发起时的请求和会话身份验证才能提交。失败后的「重试加载」「继续加载下一页」使用各自对应的请求。
- 预取由接近页尾触发，消耗现有调度配额。展示用快照内的结果与游标一起使用，避免后台首屏校验抢在续页前消费同一个站点搜索间隔。

## 阅读续读与翻页

- 历史进度提供目标页码，续读索引提供能用来直接显示该页的本机文件与页表。同账号、同画廊、同页且图片可用时优先走本机。`ReaderResumeCache` 负责索引格式、文件校验与容量限制，由 `MediaRepository` 串行协调索引读写与清理，并校验图片文件是否可用。索引沿用每个账号最多 32 个画廊的边界，离线副本和历史记录各自持久化。
- 恢复时按当前屏蔽规则验证标签。旧历史可能在首次打开后才具备索引。图片缺失或损坏时恢复普通加载流程，后续照常请求所需页表和图片。
- 翻页先判断当前任务是否具备启动条件，再按需让出后台名额。松手后，最多保留一项由用户手势已经触发、仍与当前页相邻且页面 URL 一致的在途任务。它占用现有空闲后台额度，预取设为 0 时也能接着跑。再次翻到该页，原任务直接升到前台。切作品、切账号、远跳、页面来源或设置变化，以及前台需要释放名额时，保留资格失效。

## 诊断与验收

搜索探针记录 `listQueue`（请求调度等待）、`listRequest`（获配资格后的请求阶段）、`listResponse`（列表整体等待）和 `metadataBatch`（资料补齐）。探针同时记录首屏与续页何时产生可展示结果。Release 中的生产路径不启用这些探针。现有 3.1 秒搜索发起间隔继续由站点调度器管理。发布表现以当前构建的真机样本为准，测试夹具和旧构建用于定位与回归。 [站点调度](../App/SiteRequestScheduler.swift) · [搜索探针](../App/SearchDeviceProbe.swift) · [阅读诊断](../App/ReaderNetworkMetrics.swift)

| 场景 | 应检查的结果 | 验证层级 |
| --- | --- | --- |
| 同查询重复打开 | 新鲜快照直接给结果和游标，续页能继续。显式刷新、过期快照、缺失或不完整快照发站点请求。 | [分页单元测试](../UnitTests/GalleryPagerTests.swift) |
| 查询与账号隔离 | 不同站点或账号的快照不串用。分页顺序、严格评分、当前屏蔽和失败后继续语义一致。 | 分页、解析与模拟器回归 |
| 历史续读 | 重新建立会话后命中同页；文件丢失、损坏或标签屏蔽时进入对应回退。覆盖存量文件与清理边界。 | [仓库单元测试](../UnitTests/MediaRepositoryV14Tests.swift)与模拟器回归 |
| 阅读翻页 | 邻近折返使用原在途工作；前台优先、远跳取消、旧账号结果不能回写。 | [阅读媒体单元测试](../UnitTests/ReaderMediaStoreTests.swift)与模拟器回归 |
| 真机性能 | 固定账号、网络、画廊及搜索条件。记录从历史点击到首帧、翻页到出图、页尾停顿，同时采集调度时间、在途复用和取消次数。区分冷缓存与暖缓存。 | 同一设备对比 |
| Release 覆盖 | Release 构建使用目标设备已有应用身份。安装后读回构建号、启动结果，按一致的口径复核阅读记录、收藏、搜索记录和缓存。 | 真机安装验收 |

调试采样以请求阶段、时间、页码与必要结果计数为主。诊断记录避免携带账号身份、请求地址和凭证。本机日志保存在 QA 输出目录。
